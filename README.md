#GalaxyTyper_Defend the Universe
Defend the Universe – A Space-Themed Typing Game Using the MERN Stack

Galaxy Typer is a browser-based typing game that transforms typing practice into an exciting space adventure. Players defend their spaceship by typing words displayed on incoming enemies before they reach the player. The game is designed to improve typing speed and accuracy while providing an engaging and interactive gaming experience.

Built using the MERN Stack (MongoDB, Express.js, React.js, Node.js), Galaxy Typer includes user authentication, score tracking, player profiles, and an online leaderboard.

Features:
-> User Registration & Login
-> Space-themed typing gameplay
-> Real-time typing detection
-> Random word generation
-> Increasing difficulty levels
-> Score calculation and tracking
-> Online leader board
-> Player profile management
-> Secure data storage using MongoDB
-> Responsive user interface

How to Play:
-> Register or log in to your account.
-> Start a new game.
-> Enemy ships carrying words will appear.
-> Type the displayed word correctly.
-> The enemy is destroyed when the word is completed.
-> Earn points for every correct word.
-> Progress through higher difficulty levels.
-> Try to achieve the highest score and climb the leader board.
